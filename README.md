# Brickyard — сайт Discord-сервера

Одностраничный лендинг сервера **Brickyard | 🍷**: описание, статистика, правила,
каналы, инвайт и скрытые отсылки.

- **Сайт:** https://att4cking-812.github.io/brickyard/
- **Аркада:** https://att4cking-812.github.io/arcade/
- **Инвайт:** https://discord.gg/nWAATWnnnJ

## Что внутри

- `index.html` — вся страница: стили и скрипты в одном файле
- тёмная «винная» тема, адаптив, анимации появления при скролле
- данные подтянуты через Discord-бота (участники, каналы)
- Open Graph-превью для красивых карточек в Discord/Telegram
- кнопка «наверх», ховер-эффекты, скрытый переход в аркаду по футеру

## Как обновить

1. Правь `index.html`.
2. Закоммить в ветку `main` — GitHub Pages пересоберёт сам.
3. Через минуту изменения на сайте.

Хостинг: **GitHub Pages** (Settings → Pages → Deploy from a branch → `main` / root).
